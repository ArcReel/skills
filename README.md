# ArcReel skills

Public Agent skills for connecting an external Agent to [ArcReel](https://github.com/ArcReel/ArcReel).

## Install

```bash
npx skills add ArcReel/skills
```

The package contains:

- `setup-arcreel-skills` — connect an Agent host to ArcReel MCP and verify access.
- `video-workflow` — route ArcReel video creation through the server's workflow plan.

This repository is a lightweight distribution mirror. Source changes are made in [ArcReel/ArcReel](https://github.com/ArcReel/ArcReel/tree/main/skills) and synced here automatically.
